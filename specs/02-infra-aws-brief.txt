What to build
Class: Terraform in Local and AWS (International Student Class).

OBJECTIVE

Take the API from task 1 to AWS with infrastructure as code: VPC, security groups, EC2 and an Application Load Balancer, protected by an API key.

WHAT TO BUILD

1
Create an IAM user for Terraform (not your root account), generate an access key and run aws configure with region us-east-1. Never put the keys in your repository.

2
Terraform files with the hashicorp/aws provider: version.tf, provider.tf, variable.tf (aws_region, instance_type t3.micro, instance_count, allowed CIDR blocks), vpc.tf (VPC, two public subnets, internet gateway, route table), security.tf (ALB open on 80, instances reachable only from the ALB), compute.tf (EC2 with user data that installs Docker and runs your API), alb.tf (load balancer, target group with a /health check, listener) and outputs.tf (api_url).

3
The API must reject requests without an X-API-Key header with 401. Generate the key with the random provider and expose it as a sensitive output.

4
terraform plan -out tfplan, then terraform apply tfplan. Show the resource count Terraform created.

5
Call the ALB URL without the header (401) and with it (200, a real /score result).

6
terraform destroy and show in AWS Resource Explorer or the console that nothing is left.

Cost: stay on the free tier where you can (t2.micro or t3.micro), and run terraform destroy or delete the VM the same day. Show in your video that nothing is left running.
